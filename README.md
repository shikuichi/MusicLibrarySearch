# Music Library Search (音楽ファイル検索ツール)

ブラウザ単体で高速に動作する、クライアントサイド完結型の音楽ライブラリ検索・インデックスツールです。  
大量のローカル音楽ファイルをWeb Workerによるバックグラウンド並行処理でスキャンし、即座に検索・パス取得ができます。

---

## 主な特徴

- **完全クライアントサイド動作**  
  サーバーへのアップロード等は一切行いません。すべてのファイル解析・処理はお手元のブラウザ内で完結するため、機密性の高いライブラリでも安全に利用できます。
- **Web Worker による非同期・並行処理**  
  大量の音楽ファイル（数万〜十万件規模）をブラウザの描画を固めずにスキャン可能。CPU負荷（高速／中速／低負荷）のリアルタイム切替にも対応しています。
- **タグ情報の高速抽出 (ID3v2)**  
  MP3ファイルのヘッダから直接ID3v2タグ（タイトル・アーティスト・アルバム）をバイナリ解析。タグが存在しない場合や他フォーマットでも、フォルダ階層・ファイル名パターンからメタ情報を自動推測します。
- **柔軟な絞り込み検索**  
  タイトル、アーティスト、アルバム、または全体からの横断検索に対応。スペース区切りによるAND検索も可能です。
- **ワンクリックでのパス取得**  
  検索結果のファイルパスをクリックするだけで、クリップボードへ即座にコピーできます（ラジオ放送の選曲卓やPA現場での送出指定などに最適です）。
- **インポート / エクスポート機能**  
  スキャンしたインデックス情報はJSON形式でローカルに保存・再読み込みが可能です。毎回フォルダをスキャンし直す必要がありません。
- **ダークモード自動対応**  
  OSのカラースキーム（ライト/ダーク）を自動検知して最適なコントラストに切り替わります。

---

## 対応フォーマット

以下の拡張子を持つ音楽ファイルのインデックス作成に対応しています：

`.mp3`, `.wav`, `.m4a`, `.ogg`, `.flac`, `.aac`, `.wma`, `.aif`, `.aiff`, `.alac`, `.ape`, `.opus`, `.mpc`, `.dsf`, `.dff`, `.wv`, `.mid`, `.midi`, `.tta`, `.amr`, `.caf`, `.mka`

※ID3タグのバイナリ解析は現在MP3ファイルに対応しています。その他の形式はフォルダ階層・ファイル名から自動パースされます。

## 使い方

1. `index.html`（または本ツール）をPCブラウザ（Google Chrome / Microsoft Edge など Chromium系推奨）で開きます。
2. **「フォルダを選択」** をクリックし、楽曲が格納されている親フォルダ（「ミュージック」フォルダ等）を指定します。
3. 自動的にスキャンが開始されます。完了後、検索バーからキーワードを入力して検索してください。
4. 次回以降の読み込みを短縮したい場合は、**「リストデータを出力(エクスポート)」** を押してJSONファイルを保存してください。以降は **「インポート(JSON方式)」** から一瞬でライブラリを展開できます。

> **注意:** 本ツールは大量のファイルシステム走査および一覧表示を行う都合上、PCブラウザ専用となっております（横幅600px以下の端末ではロックアウト画面が表示されます）。
